Proves ràpides:

Resultat URL Meta Quest

https://www.oculus.com/open_url/?url=https%3A%2F%2Fwww.meta.com

Estructura de la petició: oculus.com/open_url/?url=...

Codi utilitzat (JavaScript) 

function createWebLaunchUrl(linkUrl) {
  const targetUrl = new URL(linkUrl);
  if (targetUrl.protocol !== "https:") {
    throw new TypeError("Web Launch targets must use HTTPS.");
  }

  const webLaunchUrl = new URL("https://www.oculus.com/open_url/");
  webLaunchUrl.searchParams.set("url", targetUrl.toString());
  return webLaunchUrl.toString();
}

Com funciona el Web Launch?

Aquest sistema permet llançar llocs web directament al navegador de Meta Quest des d'enllaços externs o codis QR. Per motius de seguretat, Oculus exigeix obligatòriament que la URL de destí faci servir el protocol HTTPS.
